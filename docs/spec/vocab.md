# Controlled Vocabulary

**상태:** 채택 (2026-04-25)
**버전:** v1.0

`data/source/곡정보.xlsx`의 **색인** 시트와 파생 `songs.json`의 `색인` 카테고리에서 허용되는 값 목록.

## 적용 범위

색인 8 카테고리 중 **4개**는 vocab 제약이 있고, 4개는 자유 형식이다.

| 카테고리 | 제약 종류 | 정의 위치 |
|---|---|---|
| `시기` | 고정 5개 | 이 문서 |
| `성월` | 고정 12개 | 이 문서 |
| `역할` | 고정 vocab | 이 문서 |
| `느낌` | 고정 vocab | 이 문서 |
| `성경` | 정규 형식 | [schema.md](schema.md#성경-키-정규화-규칙) |
| `대축일` | 자유(공식명) | — |
| `키워드` | 완전 자유 | — |
| `곡모음집` | 자유(성가집/곡집명) | 이 문서(예시) |

`add-tag` 스킬과 `validate-lyrics-format` 스킬이 이 문서를 검증 기준으로 사용.

## 시기 (5개)

전례 주년의 5개 시기. 다른 값 불가.

| 값 | 설명 |
|---|---|
| `대림` | 대림시기 (Advent) |
| `성탄` | 성탄시기 (Christmas) |
| `사순` | 사순시기 (Lent) — 성주간 포함 |
| `부활` | 부활시기 (Easter) — 성령강림대축일까지 |
| `연중` | 연중시기 (Ordinary Time) |

## 성월 (12개)

숫자월 형식. 가톨릭 교회의 주요 성월 관련 곡에만 태깅.

| 값 | 의미 있는 성월 |
|---|---|
| `1월` | — |
| `2월` | — |
| `3월` | 성 요셉 성월 |
| `4월` | — |
| `5월` | 성모 성월 |
| `6월` | 예수 성심 성월 |
| `7월` | — |
| `8월` | — |
| `9월` | 순교자 성월 |
| `10월` | 묵주 성월 / 전교의 달 |
| `11월` | 위령 성월 |
| `12월` | — |

의미 없는 월(1·2·4·7·8·12)은 해당 월 대축일만 있고 별도 성월 주제가 없어 보통 태깅하지 않지만 필요 시 허용.

## 역할 (미사 순서)

곡이 미사 중 어느 순서에 쓰이는지. 복수 가능 (예: 봉헌·파견 겸용).

| 값 | 설명 |
|---|---|
| `입당` | 입당 성가 (Introit) |
| `봉헌` | 봉헌 성가 (Offertory) |
| `성체` | 성체 성가 (Communion) |
| `파견` | 파견 성가 (Recessional) |
| `묵상` | 묵상 성가 (Meditation) — 성체 후, 독서 사이 등 |
| `감사` | 감사 찬미가 |
| `찬미` | 찬미가 (일반) |
| `화답` | 화답송 (Responsorial Psalm) |
| `주님의기도` | 주님의 기도 성가 |
| `마침` | 마침 성가 (파견과 구분되는 경우) |

## 느낌 (분위기)

곡의 음악적·정서적 성격. 복수 가능 (예: 활기찬·선포 겸용).

| 값 | 설명 |
|---|---|
| `활기찬` | 빠르고 에너지 있음. 부활·파견에 적합 |
| `장엄한` | 웅장하고 무게감 있음. 대축일·영광송에 적합 |
| `서정적` | 부드럽고 감성적. 묵상·성모 주제에 적합 |
| `고요한` | 느리고 정적. 침묵·묵상에 적합 |
| `기쁜` | 밝고 유쾌. 성탄·감사에 적합 |
| `애원하는` | 간절한 호소. 사순·통회에 적합 |
| `선포` | 강한 메시지·공표. 복음 선포·파견에 적합 |
| `묵상적` | 내면적 사색. 성체·개인 기도에 적합 |

## 성경 (형식 규칙)

vocab 제약 없음. 다만 **정규 형식**만 허용:

```
{책약어}{장}:{절시작}-{절끝}
```

- 공백 없음, 한글 약어
- 단일 절: `마태5:3` (절시작==절끝이면 `-끝` 생략)
- 장 전체: `시편23`
- 여러 구간: 여러 엔트리로 분리

허용 책 약어 목록은 [schema.md의 성경 키 정규화 규칙](schema.md#성경-키-정규화-규칙) 참조.

## 대축일 (자유 — 공식명)

vocab 제약 없음. 단 한국천주교주교회의(CBCK) 공식 대축일명 사용 권장.

주요 예시:
- `부활대축일`
- `성탄대축일`
- `성령강림대축일`
- `성모승천대축일`
- `원죄없이잉태되신성모마리아대축일`
- `그리스도왕대축일`
- `예수성심대축일`
- `삼위일체대축일`
- `주님공현대축일`
- `예수성탄대축일` (`성탄대축일`과 동의, 한쪽 통일 권장)

## 곡모음집 (자유 — 성가집/곡집명)

vocab 제약 없음. 곡이 수록된 **성가집 또는 곡집의 이름**을 기입한다. 곡이 여러 모음집에 수록되어 있으면 복수 태깅 가능.

### 예시

| 값 | 설명 |
|---|---|
| `가톨릭성가` | 한국 천주교주교회의 공식 가톨릭성가집 (1~527번) |
| `야훼이레` | 야훼이레 성가집 |

### 권장 규칙

- **정식 명칭** 사용 (약어·속어 지양)
- 공백·특수문자 최소화 (예: `"카톨릭 성가"` 대신 `"가톨릭성가"`)
- 같은 모음집은 **표기 통일** (한 프로젝트에서 하나의 표기만 사용)
- 수록곡 번호가 필요하면 별도 필드(향후 확장) — 지금은 태그만

### 운용

- 새 모음집을 등장시킬 때 이 섹션 예시에 추가하면 다른 곡에 태깅 시 참조 가능
- 한국천주교주교회의 공식 성가집이 아닌 특정 단체/본당 성가집도 자유 기입

## 키워드 (완전 자유)

vocab 제약·형식 제약 모두 없음. 사용자가 가사 속 핵심어·주제·감정·상황 등을 자유롭게 기입.

단 권장사항:
- 한 태그 = 한 단어 또는 짧은 구 (긴 문장 금지)
- 공백·특수문자 최소화
- 같은 의미는 표기 통일 (예: `목자` vs `착한목자` 중 하나로 고정)

## vocab 업데이트 절차

**추가**
1. 이 문서에 새 값 추가 + 설명
2. `docs/spec/decisions/ADR-NNN-vocab-update.md` 작성 (간단 ADR)
3. 기존 xlsx에서 유사 값이 있으면 일괄 교체 여부 결정

**제거·변경**
1. 영향 받는 곡 수 확인 (xlsx `색인` 시트에서 `타입=XXX AND 값=YYY` 필터)
2. 마이그레이션 계획 수립
3. ADR 작성

vocab 확장은 느슨하게 허용(특히 `역할`·`느낌`), 제거는 엄격하게.
