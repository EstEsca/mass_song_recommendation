# 가사 형식 스펙

**버전:** 1.0
**확정일:** 2026-04-17

songs.json의 `가사.본문` 및 `가사.절별` 필드가 준수해야 하는 형식.

## 본문 형식 (가사.본문)

### 다절 곡

```
[1절] 거룩하다 부활이여 기쁘도다 알렐루야 예수 부활 아니시면 구속사업 헛되도다
[2절] 인류구원 하시고자 사람됨을 마다 않고 천주성자 강생하사 십자가에 죽으셨네
[3절] 죽으신지 사흘만에 우리주님 전능으로 영혼육신 결합하사 새벽녘에 부활했네
[4절] 부활하신 우리 주께 영원무궁 영광이여 부활하신 우리 주여 우리 부활 시키소서
[후렴] 알렐루야 알렐루야 알렐루야 예수 부활이여 영광이여 우리 주 예수께
```

### 통절 곡

```
[1절] 예수님 나의 주인이시어 사랑합니다 라고 고백했을 때 주께서 나를 받아 주셨네 참된 삶을 나에게 주셨네 예수님 나의 피난처시여 가장 귀한 분 나의 주님이시여 유일한 나의 기쁨 되시니 오직 감사 찬양을 드리네 주님 사랑합니다 주님 사랑합니다 나의 모든 것 되신 주님 당신을 사랑합니다
```

## 규칙

1. **절 마커**: 각 줄은 `[N절]`, `[후렴]`, `[브릿지]`, `[코다]` 등 대괄호로 시작
2. **한 줄 규칙**: 한 절의 가사는 한 줄에 전부 (절 내부 줄바꿈 없음)
3. **절 구분**: 절 사이는 `\n`으로 구분
4. **절 번호**: 1부터 순차 증가 (빠짐 없이)
5. **통절 곡**: `[1절]` 하나만 사용, 절구조는 `"통절"`
6. **오염 금지**: Copyright, 코드 심볼, 깨진 텍스트 포함 불가

## 허용되는 절 마커

| 마커 | 용도 |
|------|------|
| `[1절]` `[2절]` ... | 각 절 |
| `[후렴]` | 후렴 (refrain) |
| `[브릿지]` | 브릿지 |
| `[코다]` | 코다/마침 |
| `[전후렴]` `[후후렴]` | 전후렴/후후렴 (있는 경우) |

## 절별 형식 (가사.절별)

```json
{
  "1절": "거룩하다 부활이여 기쁘도다 알렐루야...",
  "2절": "인류구원 하시고자...",
  "후렴": "알렐루야 알렐루야..."
}
```

- 키: 마커에서 대괄호를 제거한 것 (`1절`, `후렴` 등)
- 값: 해당 절의 가사 (마커 제외, 순수 텍스트)
- 통절 곡: `{"1절": "..."}`

## 절구조 형식 (가사.절구조)

```
"1-2-3-후렴"
"통절"
"1-후렴-2-후렴"
"전후렴-1-2-3-4-후후렴"
```

- 절별 키를 `-`로 이어붙인 문자열
- 통절은 `"통절"`
