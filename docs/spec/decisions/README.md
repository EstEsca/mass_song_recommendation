# 주요 결정 이력 (Architecture Decision Records)

중요한 기술적/방향성 결정을 기록하는 폴더입니다.

## 파일 명명 규칙

```
ADR-{3자리번호}-{주제-슬러그}.md
```

예시:
- `ADR-001-crawler-source-policy.md`
- `ADR-002-skill-separation-find-vs-repair.md`

## ADR 템플릿

각 ADR 파일은 다음 형식을 따릅니다:

```markdown
# ADR-NNN: [결정 제목]

**일자:** YYYY-MM-DD
**상태:** 제안 | 채택 | 폐기 | 대체됨(ADR-XXX)

## 맥락

왜 이 결정이 필요했는가? 어떤 문제를 해결하려 했는가?

## 결정

무엇을 결정했는가? 구체적으로.

## 대안

고려했던 다른 선택지들. 왜 채택하지 않았는가.

## 결과

이 결정으로 인한 영향. 긍정적/부정적 측면 모두.

## 참조

관련 이슈, 문서, 외부 자료 링크
```

(프로젝트 진행하며 누적)
