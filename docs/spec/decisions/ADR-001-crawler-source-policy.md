# ADR-001: 크롤링 소스를 maria.catholic.or.kr로 제한

**일자:** 2026-04-16
**상태:** 채택

## 맥락

청소년청년성가집 495곡의 가사 DB를 구축하기 위해 여러 웹 소스 조사.
- 저작권 있는 가사 보호 대상
- 각 사이트의 robots.txt 정책 상이
- 일부 사이트는 AI 크롤러 명시적 차단 (gasazip.com 등)

## 결정

**maria.catholic.or.kr만 자동 크롤링 대상으로 채택.**

- CBCK 공식 사이트
- robots.txt 개방적 (성가 페이지 허용)
- User-Agent 명시 + 1.5초 지연으로 서버 부담 최소화
- 약 527곡 확보 가능

나머지 소스는:
- bugs/melon/genie: robots.txt 차단 → 제외
- 가사 DB 사이트(gasazip 등): AI 차단 → 제외
- 유튜브 임베드 사이트(chant21 등): 가사 없음 → 제외
- 쇼핑몰(paolo.kr 등): 가사 없음 → 제외

## 대안

1. **Selenium으로 robots.txt 우회** — 기각 (ToS 위반, 법적 리스크)
2. **CCLI 라이선스 구입** — 제외 (가톨릭 성가 커버 부족)
3. **CBCK 공식 API 요청** — 향후 고려 (현재 미진행)

## 결과

- **긍정**: 법적 안전, 173곡 매칭 성공 (청소년청년성가집 기준)
- **부정**: 나머지 322곡은 다른 경로(OCR, 수작업) 필요

## 참조

- 청소년청년성가집 곡목록 매칭 분석
- 각 사이트 robots.txt 조사 결과 (2026-04-16)
