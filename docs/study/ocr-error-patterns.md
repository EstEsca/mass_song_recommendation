# OCR 오류 패턴 — 한국 성가집

**작성일:** 2026-04-18
**관련 프로젝트 맥락:** 청소년청년성가집 PDF에서 곡목록 추출 시 발견된 작곡자명 OCR 오류 14건 교정

## 한 줄 요약

PDF 텍스트 추출 시 한국어 작곡자 이름에서 **초성이 유사한 글자로 대체**되는 패턴이 반복 발견됨.

## 발견된 오류 패턴

### 초성 혼동 (가장 빈번)

| 정확한 글자 | 잘못 읽힌 글자 | 예시 | 건수 |
|-----------|------------|------|------|
| **원** | 류, 권, 문 | 원선오 → 류선오, 권선오, 문선오 | 3건 |
| **정** | 전 | 서정호 → 서전호 | 1건 |
| **행** | 현 | 서행자 → 서현지 | 1건 |

### 종성 혼동

| 정확한 글자 | 잘못 읽힌 글자 | 예시 | 건수 |
|-----------|------------|------|------|
| **숙** | 수 | 최현숙 → 최현수 | 1건 |
| **영** | 중 | 성기영 → 성기중 | 1건 |
| **영** | 경 | 김수영 → 김수경 | 1건 |

### 이니셜 혼동 (외국어)

| 정확 | 오류 | 예시 |
|------|------|------|
| P. | F. | P. Lambillotte → F. Lambillotte |
| P.P. Bilhorn | P. F. Battori | 완전히 다른 이름으로 읽힘 |

## 이 프로젝트에서의 활용

### 검증 방법론 (효율 순)

1. **maria DB 로컬 교차 검증** (무료, 즉시)
   - 가톨릭성가 매칭 곡 ~170곡 대상
   - 정규화 비교로 불일치 자동 감지
   - 불일치를 포함관계/작곡작사혼동/오기의심/표기차이로 분류

2. **OCR 패턴 스캔** (무료, 즉시)
   - 알려진 혼동 글자 테이블로 의심 곡 자동 추출
   - 1회 등장 작곡자 → 오기 가능성 높음

3. **웹 검증** (고비용, 명시 요청)
   - 의심 곡에 대해 WebSearch로 교차 확인
   - 곡당 1회, 에이전트당 5곡 이하

### 교정 적용 순서

1. 패턴 스캔으로 의심 곡 추출
2. maria DB 대조로 정답 후보 확인
3. 웹 검증으로 최종 확인
4. songs.json 교정 + git 커밋

## 핵심 포인트

- **"원선오"는 OCR의 최대 피해자** — 류/권/문으로 3회 잘못 읽힘
- **단일 글자 차이면 항상 의심** — 특히 초성/종성 유사 시
- **1회 등장 작곡자는 오기 가능성** — 빈도 분석이 1차 필터
- **maria DB가 가장 신뢰할 수 있는 진리표** — 공식 사이트
- **웹 검증은 마지막 수단** — 토큰 비용 큼, 의심 곡에만 적용
