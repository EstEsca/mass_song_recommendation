# S-003: 가사 완전 복구 및 DB화

**상태:** 보류
**기간 시작:** 2026-04-20
**기간 종료:** 미정 (S-004 활성화로 2026-04-20 보류 전환)

## 목표

493곡(현재 확보분) + 2곡(영어곡) = 495곡 전체의 가사를 **최종 품질 수준**으로 복구하여 선곡 추천에 쓸 수 있는 DB로 완성.

### 핵심 원칙

1. **사용자가 권위 있는 소스**에서 가사를 수동 입력 (합법 보유 자료 사용)
2. **Claude는 형식 보정만** 담당 (띄어쓰기, 마커 변환, 절 분리, 절구조 재생성)
3. **가사 본문은 사용자 또는 크롤링 원본에서만** 유입, Claude가 새로 생성/추정하지 않음

## 완료 기준

| 기준 | 목표 |
|------|------|
| 가사 확보율 | 495 / 495 (100%) |
| 형식 통과율 | ≥ 95% (≥ 470곡) |
| 사용자 수동 입력 곡 | 추적 가능 (출처 필드에 "수작업" 표시) |
| 선곡 추천 동작 확인 | `/recommend-hymns` 실전 테스트 통과 |

## 작업 흐름

```
[대상 곡 식별]
   ↓
[사용자 가사 입력 경로]     [Claude 형식 보정 역할]
- CSV 템플릿 편집             - 띄어쓰기 자동 교정
- 직접 songs.json 편집        - [N절]/[후렴] 마커 변환
- 대화로 붙여넣기             - 영문 잔존 제거
   ↓                        - 절 구조 재생성
[songs.json 저장]             - 출처 필드 "수작업" 표시
   ↓
[validate-lyrics-format 검증]
   ↓
[선곡 추천 실사용]
```
