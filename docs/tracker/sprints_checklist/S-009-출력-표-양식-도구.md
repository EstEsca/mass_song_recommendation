## 진행 중

### Step 1. 입력 분석 + 매핑 플랜
- [ ] [👤] 첫 양식 예시 제공 (텍스트 또는 이미지)
- [ ] [🤖] Claude가 입력 분석 — 컬럼·행·헤더·머지·정적/동적 영역 보고
- [ ] [🤖] 추천 결과 필드(번호·제목·작곡자·요약 등)와 양식 셀 매핑 가설 제시
- [ ] [👤] 매핑 가설 검수, 수정·확정 (블로킹)
- [ ] [🤝] 매핑 규칙 표현법 합의 — placeholder 치환 / JSONPath / Python 식 (블로킹)

### Step 2. 디렉토리·메타 스키마 설계
- [ ] [🤖] `data/source/output_templates/` 디렉토리 신설
- [ ] [🤖] `data/source/output_templates/README.md` 작성 (사용법 + 인덱스)
- [ ] [🤖] 메타 JSON 스키마 확정 (스프린트 본문 안 참조)

- [ ] [👤] 첫 템플릿 검수 — 실제 양식과 일치하는지 확인 (블로킹)

### Step 3. 변환 도구 프로토타입
- [ ] [🤖] `scripts/render_output.py` 작성 — 입력: (recommend-hymns 결과 JSON, 템플릿명) / 출력: TSV (또는 xlsx)
- [ ] [🤖] dry-run + 샘플 추천 결과로 검증
- [ ] [👤] TSV 출력을 실제 엑셀에 Ctrl+V로 붙여넣어 확인 — 셀 분리 정확성 (블로킹)

### Step 4. 스킬화
- [ ] [🤝] 스킬 이름 확정 — `/format-output` 등 (블로킹)
- [ ] [🤖] `.claude/skills/<name>/SKILL.md` 작성 — 자연어 인터페이스(템플릿 선택·생성·적용)
- [ ] [🤖] `recommend-hymns`와의 연계 (옵션) — 추천 후 "양식화할까요?" 프롬프트

- [ ] [👤] 인쇄·배포 시나리오로 동작 확인 (블로킹)
