**책임 표시**: `[👤]` 사용자 / `[🤖]` Claude / `[🤝]` 공동.
**블로킹** 표시는 항목 끝에 `(블로킹)`.

---

## 시작 전

- [ ] [👤] 한 달치 추천 결과 샘플 1건(또는 직전 미사 4주차 묶음) 준비 — 변환 입력 검증용 (블로킹)
- [ ] [👤] Google Sheets 협업 양식의 컬럼 구성 확인 (캡처 또는 헤더 텍스트) (블로킹)
- [ ] [🤖] `pyperclip` 등 클립보드 라이브러리 의존성 확인 (없으면 `clip.exe` 파이프로 폴백)
- [ ] [🤖] `scripts/serialize_candidates.py` 직렬화 패턴 재독 — 재사용 포인트 정리

## 진행 중

### Step 1. 한 달치 프리셋 1개 함께 작성 (Google Sheets용)
- [ ] [🤝] 사용자와 함께 한 달치 Google Sheets 양식 1개 직접 작성 — 컬럼·행 구성 합의 (블로킹)
- [ ] [🤖] `data/source/output_presets/` 디렉토리 신설
- [ ] [🤖] `month-google-sheets.json`(매핑 규칙) + `month-google-sheets.tsv`(빈 양식) 작성
- [ ] [👤] 빈 양식을 실제 Google Sheets에 Ctrl+V로 붙여넣어 셀 분리 확인 (블로킹)

### Step 2. 두 번째 프리셋 (마크다운)
- [ ] [🤖] `month-markdown.json` + `month-markdown.md` 작성 — 주일별 표 + 카테고리 행
- [ ] [👤] 마크다운 표를 협업 문서(Docs/Notion 등)에 붙여넣어 렌더 확인

### Step 3. 변환 도구 프로토타입
- [ ] [🤖] `scripts/render_output.py` 작성 — 입력: 추천 결과 JSON + 프리셋명 / 출력: stdout + temp 파일 + 클립보드
- [ ] [🤖] `temp/output/` 디렉토리 자동 생성 + `.gitignore` 등록
- [ ] [🤖] 파일 상단 주석(생성 시각·프리셋명·소스 식별자 1~3줄) 포맷 결정·구현
- [ ] [🤖] 클립보드 복사 검증 (Windows)
- [ ] [👤] 한 달치 샘플로 dry-run → 두 프리셋 모두 정상 출력 확인 (블로킹)

### Step 4. `/recommend-hymns` 통합
- [ ] [🤖] SKILL.md에 한 달치 추천 종료 후 "출력 양식 변환?" 자동 프롬프팅 분기 추가
- [ ] [🤖] 프리셋 목록은 `data/source/output_presets/` 스캔으로 동적 노출
- [ ] [🤖] "건너뛰기" 옵션 포함
- [ ] [👤] 실제 추천 흐름 1회 돌려보고 프롬프팅·변환·붙여넣기 전체 동작 확인 (블로킹)

### (범용)
- [ ] [🤖] 진행 로그를 스프린트 본문 "진행 로그"에 기록
- [ ] [🤖] 새 점검 항목 발견 시 이 체크리스트에 추가

## 완료 전

- [ ] [🤖] 한 달치 Google Sheets 프리셋 — Sheets Ctrl+V 셀 분리 정확 (블로킹)
- [ ] [🤖] 한 달치 마크다운 프리셋 — 협업 문서에서 표로 렌더 (블로킹)
- [ ] [🤖] 클립보드 자동 복사 동작 (블로킹)
- [ ] [🤖] `temp/output/` 파일에 생성 맥락 주석 포함 저장 (블로킹)
- [ ] [🤖] 사용자 화면에 매핑 식·placeholder·JSON 노출 없음 (검수)
- [ ] [🤖] `/recommend-hymns` 통합 후 "건너뛰기" 정상 (블로킹)
