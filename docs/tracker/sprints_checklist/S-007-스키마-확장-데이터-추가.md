## 진행 중

### Step 1. 필드·vocab 확정
- [ ] [🤖] `docs/spec/schema.md` v2.x 초안 갱신 (신규 필드 추가, 매핑 규칙)
- [ ] [🤖] 새 필드 중 vocab 대상이 있으면 `docs/spec/vocab.md`에 섹션 추가 (예: 조표 vocab)
- [ ] [🤖] `docs/spec/decisions/ADR-007-스키마-v2.x-확장.md` 작성 (확장 근거·대안·결과)
- [ ] [👤] 초안 검수 + 승인 (블로킹)

### Step 2. xlsx 컬럼 추가
- [ ] [🤖] `data/source/곡정보.xlsx`의 `곡목록` 시트(또는 적절한 시트)에 새 컬럼 추가
- [ ] [🤖] 기존 셀 보존 검증 — `python scripts/rebuild.py --check`로 sha256 갱신만 확인
- [ ] [🤖] 변경 후 round-trip 테스트 (xlsx → JSON → xlsx 무손실)

### Step 3. 자동 추출 (해당 시)
- [ ] [🤖] PDF 또는 기존 데이터에서 자동 추출 가능성 탐색 (예: 첫 마디 조표 patterns)
- [ ] [🤖] 추출 스크립트 작성 (있다면 `scripts/extract_<field>.py`)
- [ ] [🤖] 결과를 `data/source/곡정보.xlsx`에 적용 (또는 jsonl + apply_to_xlsx 패턴)
- [ ] [👤] 자동 추출 결과 sample 검수 — 정확도 확인 (블로킹)

### Step 4. 수작업 입력 경로
- [ ] [🤖] 자동 추출 못 한 곡의 수작업 입력 가이드 (엑셀 직접 또는 `/add-tag` 확장 등)
- [ ] [👤] 수작업 곡 데이터 입력 (필요 시 점진)

### Step 5. 빌드 파이프라인·뷰 연동

- [ ] [🤖] 뷰어(`server/`) 어댑터에 새 필드 노출 (필요 시)
- [ ] [🤖] `recommend-hymns` 스킬이 활용 가능하도록 SKILL.md 갱신 (필요 시)
