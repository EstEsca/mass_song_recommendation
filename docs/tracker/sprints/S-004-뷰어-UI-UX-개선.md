## 구현 산출물

### 백엔드
- `viewer/server.py` — 로컬 편집용 HTTP 서버 (stdlib only)
  - `GET /api/songs` — 전체 반환
  - `PUT /api/songs/<번호>` — 가사/검증완료 필드 패치
  - 원자적 쓰기 (tmp → rename), 127.0.0.1 고정 바인딩
  - 허용 필드 화이트리스트: `가사.본문/절별/절구조/참조URL`, `검증완료`

### 프론트엔드 (`viewer/index.html`)
- **레이아웃 2열 재구성**: 좌(통계+필터+테이블) / 우(상세+에디터)
- **항상-편집 모드**: 곡 선택 시 에디터 자동 활성
- **autosave-on-navigation**: 다른 곡 이동 시 자동 저장, 실패/빈본문 시 이동 차단
- **Esc 되돌리기**: 현재 변경을 마지막 저장 상태로 복원
- **Ctrl+S 명시 저장**: 빈 본문도 허용
- **실시간 프리뷰**: 섹션 카드 분리 + F1/F2/F5/F6 배지
- **마커 시스템**
  - `*` 사용자수정 마커 (신뢰도 배지 옆)
  - `●` dirty 마커 (저장되지 않은 변경)
  - `✓` 검증완료 체크박스 (테이블 + 상세)
- **네비게이션**: j/k 이동, ◀/▶ 버튼, 진행도 `n / m`
- **편집상태 필터**: 위반/미편집/수정됨/검증완료/검증안됨
- **경쟁 상태 방어**: 저장 중 곡 전환, 연타 방지 (`navigating`/`saving` 가드)

### 문서
- `viewer/README.md` — 실행법/단축키/API/저장 시맨틱/git 안전망

### 데이터 스키마 확장
- `song.사용자수정시각` (ISO 타임스탬프) — 가사 편집 시 서버가 기록
- `song.검증완료` (boolean) — 수동 검증 체크 (별도 의미, 사용자수정시각 안 건드림)

- **검증 체크박스 분리**: 가사 편집(`사용자수정시각`)과 검수(`검증완료`)를 독립 필드로 둬서 의미가 섞이지 않음.
