# S-012: 출력 양식 프리셋 (선곡 결과 → 협업 양식 변환)

**상태:** 활성
**기간 시작:** 2026-04-30
**기간 종료:** —

## 목표

1. **한 달치 미사 전체** 단위로 추천 결과를 협업 매체에 붙여넣을 수 있는 프리셋 2종 직접 작성: Google Sheets용 TSV, 마크다운 표.
2. `/recommend-hymns` 한 달치 추천 종료 시 "출력 양식으로 변환할까요?"를 자동 프롬프팅하는 흐름을 SKILL.md에 추가.
3. 변환 도구(`scripts/render_output.py`) 프로토타입: 추천 결과 + 프리셋 → 결과 텍스트 + 클립보드 복사 + `temp/output/` 파일 보존(생성 맥락 주석 포함). 매핑 식은 사용자에게 노출하지 않음.

## 배경

- 사용자는 Google Sheets(공유 시트)와 마크다운 문서로 협업. 한 달 단위로 미사 선곡 묶음을 다듬는 흐름이라, 추천 한 달치 → 협업 매체 붙여넣기 비용이 큼.
- S-009와는 방향이 반대 — S-009: 외부 → 우리 로그 / S-012: 우리 추천 → 외부 협업 매체.
- 1차 범위는 "한 달치 프리셋 2종 + 변환 도구 + 클립보드 복사 + temp 파일 보존". 신규 프리셋 등록 흐름·Google Sheets API·xlsx 머지/서식은 모두 스코프 OUT.

## 확정 사양

- **프리셋 단위 = 한 달치 미사 전체** (4~5주, 카테고리별 곡 모두 포함). 본 스프린트는 이 단위 프리셋만 개발.
- **출력 매체 = 클립보드 복사 + `temp/output/` 파일 출력**.
  - 사용자는 클립보드 내용을 Google Sheets 또는 마크다운 문서에 그대로 붙여넣기만 하면 됨.
  - 동시에 `temp/output/<timestamp>_<preset>.<ext>` 형태로 파일 보존. 파일 상단에 짧은 주석(생성 시각·프리셋명·소스 추천 식별자 등 1~3줄).
- **매핑 식(placeholder, 직렬화 규칙 등)은 사용자에게 노출하지 않음.** 내부 구현 디테일로만 존재. 사용자는 "프리셋 선택 → 결과 텍스트"만 본다.
- **프리셋 신규 등록 흐름은 본 스프린트 스코프 OUT.** 이번 스프린트에서 함께 작성한 프리셋만 사용. 등록 자동화는 후속 스프린트로 분리.

## 범위 — 4단계

### Step 1. 프리셋 디렉토리 + 한 달치 프리셋 2개 직접 작성
- `data/source/output_presets/` 신설
- `month-google-sheets.json` + `month-google-sheets.tsv` — Google Sheets에 Ctrl+V로 붙여넣을 TSV. 행=주일×카테고리, 열=주일/전례명/카테고리/번호/제목/작곡자/선정이유 등.
- `month-markdown.json` + `month-markdown.md` — 마크다운 표 (협업 문서용).
- 메타 JSON은 내부 매핑 규칙 보관용. 디렉토리 README는 향후 등록 흐름이 생길 때 작성.

### Step 2. 변환 도구 프로토타입 (`scripts/render_output.py`)
- 입력: 한 달치 추천 결과 JSON + 프리셋명
- 출력:
  - (a) stdout으로 결과 텍스트
  - (b) `temp/output/<timestamp>_<preset>.<ext>` 파일에 동일 내용 저장(상단 주석 포함)
  - (c) 가능하면 OS 클립보드 자동 복사 (Windows: `pyperclip` 또는 `clip.exe` 파이프)
- 재사용: `scripts/serialize_candidates.py`의 INDEX_FIELDS 직렬화 패턴, `data/songs_index.json` lookup.

### Step 3. `/recommend-hymns` SKILL.md에 한 달치 출력 분기 추가
- 한 달치 추천이 끝난 시점에 "출력 양식으로 변환할까요? 프리셋: [month-google-sheets, month-markdown]"을 자동 프롬프팅.
- 한 주일치 추천에는 미적용 (한 달치 단위 프리셋이므로).
- 사용자가 선택하면 변환 도구 호출, 결과 표시 + 클립보드 복사 안내. "건너뛰기" 옵션 포함.

### Step 4. 통합 위치 결정
- 1차: `recommend-hymns` 내부 단계로 통합 (별도 스킬 없이).
- 추후 확장이 필요해지면 `/format-output` 등 별도 스킬로 분리.

## 완료 기준

| 기준 | 목표 |
|------|------|
| 한 달치 Google Sheets 프리셋 동작 | TSV가 Sheets에 Ctrl+V 시 정확한 셀 분리 |
| 한 달치 마크다운 프리셋 동작 | 마크다운 표가 GitHub/Notion/Docs에서 표로 렌더 |
| 클립보드 자동 복사 | 변환 직후 OS 클립보드에 결과 텍스트 적재 (Windows에서 검증) |
| temp 파일 출력 | `temp/output/` 디렉토리에 타임스탬프 파일 생성, 상단에 생성 맥락 주석 |
| 매핑 식 비노출 | 사용자 화면에 placeholder/JSON 노출 없음 |
| `/recommend-hymns` 통합 | 한 달치 추천 종료 시 자동 프롬프팅, "건너뛰기" 가능 |

## 스코프 OUT

- 한 주일치 또는 한 카테고리만의 프리셋
- 사용자가 신규 프리셋을 자연어/이미지로 등록하는 흐름 (후속 스프린트)
- Google Sheets API 직접 연동 (클립보드로 충분)
- 머지 셀·서식 보존 xlsx 출력
