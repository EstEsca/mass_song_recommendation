# S-010: 파일 관리 프로세스 리팩터링 후 수습

**상태:** 보류
**기간 시작:** 2026-04-25
**기간 종료:** —
**보류 사유:** 2026-04-25 S-007(곡 스키마 확장) 활성화로 자동 보류. 재개 시 체크리스트 "재현 케이스 확인"부터 이어가면 됨.

## 목표

1. 에디터에서 모든 곡의 가사가 빈 채로 열리는 회귀를 잡는다 — `songs.json`에는 가사가 있음에도 표시되지 않음.
2. 에디터에서 작곡자·분류·비고를 비롯한 모든 메타·색인 필드를 직접 편집할 수 있게 한다.
3. 색인 필드(전례별/시기/성월별/대축일별/관련성경구절)를 기본 메타와 같은 입구(에디터 폼)로 통합하되 vocab 검증을 유지한다.

## 배경

S-006(가사 파이프라인 재편)·S-008(스키마 v2 마이그레이션)로 SSoT를 `data/source/곡정보.xlsx`로 일원화하면서, viewer/editor 어댑터(`server/app.py`)가 v1 ↔ v2 사이를 매개하는 구조가 되었다. 이 전환의 부작용으로 두 회귀가 일상 작업을 막고 있다:

1. **편집 필드 축소** — `_validate_patch`가 `가사.본문`만 받도록 닫혀 있어 작곡자·분류·비고·색인은 에디터에서 손댈 수 없음. 표시는 되지만 폼이 아니라 read-only `meta-item`.
2. **가사 표시 누락** — `songs.json`에 가사가 있음에도 에디터에서 모든 곡이 빈 본문으로 열림. 사용자 진단: "xlsx만 참조하느라 가사를 못 긁어옴" — GET 경로 또는 어댑터가 데이터 라우팅을 잘못 하고 있음.

## 색인 필드 통합 권고

**색인을 기본 메타로 통합하되, vocab 보호는 유지.** 색인을 `/add-tag` 스킬로만 관리한 이유는 `vocab.md` 검증이 핵심이지 편집 경로 분리 자체가 본질이 아니다. 에디터에서도 vocab 검증을 거치면 동일 품질 보장이 가능.

- **에디터 폼 = 단일 편집 입구**: 제목·작곡자·분류·비고 + 색인(전례별/시기/성월별/대축일별/성경구절)을 한 화면에서 편집.
- **vocab-controlled 필드**(전례별/시기/성월별/대축일별)는 드롭다운/체크박스 UI로 vocab만 선택 가능 — 자유 입력 차단.
- **자유텍스트 필드**(작곡자·분류·비고·관련성경구절)는 input/textarea.
- `/add-tag` 스킬은 채팅에서 빠르게 태깅하고 싶을 때의 보조 입구로 유지(중복 아님 — UI vs 자연어).

## 범위 — 3-Stage

### Stage 1. 가사 사라짐 원인 진단 + 수정

- [ ] `data/songs.json`의 임의 곡 5개 표본에서 `가사` 필드 실제 내용 확인.
- [ ] `data/source/곡정보.xlsx` 가사 시트 동일 곡 표본 확인.
- [ ] 두 데이터 비교 → 진리 출처와 끊기는 지점 결정:
  - 가설 A: `songs.json`엔 있고 xlsx엔 없음 + 어댑터가 xlsx 경로로 폴백 → 어댑터 라우팅 수정.
  - 가설 B: 빌드 파이프라인이 xlsx → songs.json 재빌드 시 가사 누락. → 빌드 스크립트 수정.
- [ ] 수정 후 에디터에서 동일 곡 표시 확인.

### Stage 2. 에디터 편집 필드 확장

- [ ] **백엔드 (`server/app.py`)**:
  - `_validate_patch` 화이트리스트 확장: `제목`, `작곡자`, `분류`, `비고`, `색인.전례별`, `색인.전례시기`, `색인.성월별`, `색인.대축일별`, `색인.관련성경구절`.
  - vocab 검증: vocab-controlled 필드 PUT 시 `scripts/add_tag.py`의 vocab 헬퍼 재사용.
  - xlsx 쓰기 일반화: `_write_lyrics_to_xlsx` → `_write_field_to_xlsx(num, field, value)`로 가사·색인·메타 시트 분기.
  - 응답으로 갱신된 곡 객체 반환.
- [ ] **프론트엔드 (`viewer/index.html`)**:
  - `meta-item` 정적 표시 → input/textarea/select로 교체.
  - 색인 vocab 필드는 신규 GET `/api/vocab` 응답으로 select/체크박스 렌더.
  - 저장 UX는 기존 가사 저장 패턴 답습.

### Stage 3. 정합성 + 회귀 점검

- [ ] 에디터 저장 → xlsx 반영 → songs.json 재빌드 동기성 확인. 빌드가 수동이면 자동 트리거 또는 명시적 메시지.
- [ ] `/add-tag` 스킬과의 충돌 확인 — vocab 정의가 한 곳이어야 함 (헬퍼 일원화).
- [ ] `/clean-lyrics`, `/label-lyrics` 1곡 시연 — 회귀 없음 확인.
