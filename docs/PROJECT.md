# 성가 추천 프로젝트

## 비전

한국 가톨릭 청소년/청년 성가대의 선곡 작업을 자동화하여, 매주 전례 말씀(복음/독서)에 가장 적합한 성가를 추천받는 시스템을 구축한다.

## 최종 목표

청소년청년성가집 495곡을 데이터베이스화하고, 주일 전례 말씀에 기반하여 봉헌·성체·파견·묵상 등 카테고리별로 성가를 추천하는 Claude Code 기반 도구를 완성한다.

## 아키텍처

```
데이터 레이어
├── data/songs.json                      ⭐ 중앙 운영 데이터 (schema.md v1.0)
│
├── 입력 소스 (수정 시 songs.json 재생성)
│   ├── data/songs.json                           (단일 진리 저장소, 495곡)
│   ├── data/raw/곡목록.csv                        (495곡 기본 메타, 최초 부트스트랩용)
│   ├── data/raw/song_list_index_sample.xlsx     (색인: 전례/시기/성경구절)
│   ├── scripts/crawler/data/maria_sungga.jsonl  (가톨릭성가 크롤링 527곡)
│   └── scripts/crawler/data/yseng_sungga.jsonl  (yseng 청소년성가 수집)
│
└── 보조 도구
    ├── scripts/crawler/_merge.py        (크롤러 공용 in-place 병합 헬퍼)
    ├── scripts/crawler/crawl_maria.py   (robots.txt 준수 크롤러 + 자동 병합)
    └── scripts/crawler/crawl_yseng.py   (yseng.kr 제목 완전 일치 크롤러 + 자동 병합)

자동화 레이어 (Claude 스킬) — docs/skills_policy.md 참조
├── /extract-sheet-lyrics   [1차 추출, 로컬]     PDF → songs.json
├── /validate-lyrics         [형식 검증, 로컬]    songs.json 형식 검증
├── /repair-lyrics           [웹 복구, 고비용]    명시 요청 시에만
├── /find-lyrics             [오케스트레이터]     위 셋을 단계별 호출
├── /recommend-hymns         [전례 기반 선곡]
└── /add-issue               [이슈 추적]

외부 소스
├── cbck.or.kr              (주일 전례 말씀)
└── maria.catholic.or.kr    (가톨릭성가 공식, 이미 크롤링 완료)
```

## 담당자 역할 분담

| 유형 | 표기 | 범위 |
|------|------|------|
| Claude 단독 | 🤖 | 자동화 가능한 데이터 작업, 분석, 매칭 |
| 협업 | 🤝 | Claude 제안 → 사용자 승인 |
| 사용자 단독 | 👤 | 저작권 보유 자료 수작업, 최종 판단 |
| 외부 블로킹 | 🚧 | 외부 기관 응답 대기 |

### Claude 담당 (🤖)
- 곡 메타데이터 매칭/정규화
- 로컬 DB 조회 및 통합
- 공식 크롤러 실행 (robots.txt 준수)
- 전례 말씀 수집 (cbck.or.kr)
- 가사 분석 (주제/성경구절/카테고리 태깅)
- 추천 알고리즘 구현 및 개선
- 스킬 유지보수

### 사용자 담당 (👤)
- 합법 보유 자료 수작업 입력 (가사 322곡)
- 곡목록 비고란 메모 (떼창 적합 등)
- 저작권자 공식 문의 (CBCK, 교구청 등)
- 최종 선곡 검토/승인
- 실전 성가대 피드백 수집
- 우선순위 결정

### 협업 (🤝)
- 선곡 추천 → 검토/수정
- 가사 분류 → 검증
- 문서 업데이트 (PROJECT/STATUS)

## Phase별 로드맵

### Phase 1: 기반 완성 (현재)
**목표:** 스킬과 데이터 인프라 완성

**완료 기준:**
- 4개 스킬 작동 확인 (recommend-hymns, find-lyrics, repair-lyrics, add-issue)
- maria 크롤링 173곡이 색인 엑셀에 가사 필드로 병합됨
- 색인 엑셀의 전례/시기/성경구절 결측 필드 ≥ 80% 보완
- 추천 스킬이 더미 입력(특정 주일 날짜)에 결과 반환 가능

**소요 예상:** 1~2주

### Phase 2: 가사 DB 구축 (순차 진행)
**목표:** 322곡 수작업 가사 입력 → 전체 가사 분석

**중요: 순차 진행 원칙**
가사 입력을 **먼저 모두 완료**한 후, 가사 분석 작업을 시작한다.
분석을 병행하지 않는 이유:
- 부분 입력된 가사로 분석하면 나중에 재분석 필요
- 전체 가사가 있어야 주제/카테고리 분류의 일관성 확보
- 입력 중 포맷/스키마가 바뀌면 분석 결과가 무효화

**단계 2-A: 가사 입력 (선행)**
- 가사 입력 CSV 템플릿 제공 (🤖)
- 322곡 수작업 입력 (👤) — 사용자 주도
- 입력 형식 검증 스크립트 제공 (🤖)
- 495곡 중 400곡 이상에 가사 또는 명시적 "가사 없음" 표시

**단계 2-B: 가사 분석 (입력 완료 후)**
- 주제/키워드 추출 (🤖)
- 성경 구절 자동 매핑 (🤖)
- 카테고리 태깅: 봉헌/성체/파견/묵상 등 (🤖)
- 사용자 검증 및 교정 (🤝)

**소요 예상:** 
- 2-A: 1~3개월 (사용자 작업 속도 의존)
- 2-B: 1~2주 (2-A 완료 후)

### Phase 3: 추천 시스템 완성
**목표:** 실전 운영

**완료 기준:**
- 실제 성가대에서 4회 이상 사용
- 각 사용의 만족도/수정사항 피드백 수집
- 가중치 튜닝 2회 이상 반영
- 사용자가 Claude 없이도 선곡기록을 참조할 수 있는 형식

**소요 예상:** 2~3개월
