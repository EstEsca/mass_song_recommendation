# 상태 문서

프로젝트 현황을 한눈에 파악하는 스냅샷 문서.

## 어떤 문서를 언제 보나

| 문서 | 언제 보나 |
|---|---|
| [RESUME.md](RESUME.md) | **새 세션 시작 시 첫 진입점**. Quick Start + 읽기 순서 가이드 |
| [STATUS.md](STATUS.md) | 진척률·완료된 작업·다음 작업·블로킹 |
| [PROJECT.md](PROJECT.md) | 프로젝트 비전·목표·아키텍처 다이어그램 |

## 갱신 책임

| 시점 | 갱신 대상 |
|---|---|
| 세션 종료 시 | RESUME.md(필요 시 다음 세션 메모), STATUS.md(다음 작업 갱신) |
| 스프린트 완료 시 | STATUS.md(진척률·완료 작업) |
| 메이저 변경(스키마 버전업·아키텍처 전환) 시 | PROJECT.md, STATUS.md, RESUME.md 모두 |

## 통합 검토 (보류)

세 문서의 역할이 일부 중복돼 단일 문서로 통합하는 안이 있으나, 현재는 **분리 유지**. 차후 정비 사이클에서 결정.
