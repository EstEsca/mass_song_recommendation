# 학습노트 스킬

프로젝트를 진행하며 배운 개념, 기술, 노하우를 `docs/study/` 폴더에 정리한다.

## 저장 위치

- 노트 파일: `docs/study/{주제슬러그}.md`
- 목차: `docs/study/INDEX.md`

## 실행 흐름

### Step 1: 주제 파악

`$ARGUMENTS`에서 주제를 파싱한다.
예: "ADR이 뭔지 정리해줘" → 주제 = "ADR"

### Step 2: 노트 작성

아래 템플릿으로 `docs/study/{슬러그}.md`에 작성:

```markdown
# {주제}

**작성일:** YYYY-MM-DD
**관련 프로젝트 맥락:** 이 프로젝트에서 이 개념을 어떻게 사용했는지

## 한 줄 요약

{개념을 한 문장으로}

## 상세 설명

{개념의 정의, 배경, 목적}

## 이 프로젝트에서의 활용

{실제로 어디에 어떻게 적용했는지, 구체적 파일/결정 참조}

## 핵심 포인트

- {기억할 것 1}
- {기억할 것 2}
- {기억할 것 3}

## 참고 자료

- {관련 링크/문서}
```

### Step 3: 목차 갱신

`docs/study/INDEX.md`에 새 노트 항목 추가.

### Step 4: 확인

> 학습노트에 "{주제}"를 정리했습니다.
> 파일: docs/study/{슬러그}.md

## 원칙

- **프로젝트 맥락과 연결**: 추상적 설명만이 아니라, 이 프로젝트에서 어떻게 쓰였는지 반드시 포함
- **간결하게**: 교과서가 아니라 실무 참고 노트
- **기존 노트 업데이트**: 같은 주제가 이미 있으면 새로 만들지 않고 기존 노트에 추가
