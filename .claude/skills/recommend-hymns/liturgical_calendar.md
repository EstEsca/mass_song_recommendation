## 3. 이동 축일 (부활 기준)

부활 주일(E)을 기준으로 날짜 오프셋 계산.

| 축일 | 오프셋 | 비고 |
|------|--------|------|
| 재의 수요일 | E − 46 | 사순 시작 |
| 주님 수난 성지 주일 | E − 7 | 성주간 시작 |
| 주님 만찬 성목요일 | E − 3 | 파스카 성삼일 시작 |
| 주님 수난 성금요일 | E − 2 | — |
| 부활 성야 | E − 1 저녁 | — |
| **부활 대축일** | E | — |
| 주님 승천 대축일 | E + 40 (또는 E + 42 주일) | 한국은 주일로 이동 |
| 성령 강림 대축일 | E + 49 | — |
| 삼위일체 대축일 | E + 56 | — |
| 그리스도의 성체 성혈 대축일 | E + 60 (또는 E + 63 주일) | 한국은 주일로 이동 |
| 예수 성심 대축일 | E + 68 | 금요일 |
| 티 없으신 성모 성심 기념 | E + 69 | 토요일 |
| 그리스도 왕 대축일 | 대림 첫째 주일 − 7 | 연중 마지막 주일 |

**부활 주일 계산**: 춘분(3/21 고정 처리) 이후 첫 보름 다음 주일. Python에서는 아래 공식 사용 (Anonymous Gregorian algorithm):

```python
def easter(year):
    a = year % 19
    b = year // 100
    c = year % 100
    d = b // 4
    e = b % 4
    f = (b + 8) // 25
    g = (b - f + 1) // 3
    h = (19*a + b - d - g + 15) % 30
    i = c // 4
    k = c % 4
    l = (32 + 2*e + 2*i - h - k) % 7
    m = (a + 11*h + 22*l) // 451
    month = (h + l - 7*m + 114) // 31
    day = ((h + l - 7*m + 114) % 31) + 1
    return month, day
```

## 5. 판정 알고리즘 (스킬에서 부르는 방식)

입력: 대상 주일 날짜 `YYYY-MM-DD`

1. 해당 연도의 `easter(year)` 계산 → 이동 축일 날짜 도출
2. 고정 대축일/이동 대축일 테이블과 정확히 일치하면 **대축일 컨텍스트 ON**
3. 전례시기 구간 중 어디에 속하는지 판정 → `전례시기`
4. 월(month) 기준 성월표 조회 → `성월`
5. 반환: `(성월, 대축일_or_None, 전례시기)` 튜플

대축일이 주일과 겹치거나 주일로 이동된 경우(승천·성체성혈), 우선순위는 **대축일 > 그 주 전례시기**.

## 6. 색인 매칭 힌트

`/recommend-hymns`가 songs.json을 조회할 때 이 문서의 **매칭 키워드** 열을 사용해 다음 필드와 부분 일치 검색한다.

- `색인.성월별`
- `색인.대축일별`
- `색인.전례시기`
- `색인.비고`

예: 5월 판정 시 `성모` 또는 `마리아`를 포함한 색인 항목을 가진 곡에 가중치 부여.
