# 대화형 태그 추가 스킬

사용자가 대화 중에 곡의 색인 태그를 추가하고 싶을 때, 엑셀이나 에디터를 열지 않고 **자연어로 즉시 반영**한다.

## 데이터 흐름

```
사용자 자연어 입력
   "2번 곡에 키워드 갈릴래아 추가해줘"
        │
        ▼
스킬이 (번호, 타입, 값) 파싱
        │
        ▼
scripts/add_tag.py 호출
   - vocab 검증 (느낌/역할/시기/성월)
   - 중복 체크
   - 곡정보.xlsx의 색인 시트에 행 append
   - xlsx 잠금 시 안내 후 재시도
        │
        ▼
사용자에게 결과 보고 + rebuild 안내
```

## 자연어 파싱 가이드

다음 패턴들을 인식해 `(번호, 타입, 값)` 추출:

| 사용자 입력 예 | 파싱 결과 |
|---|---|
| "2번 곡에 갈릴래아 키워드 추가" | (2, 키워드, 갈릴래아) |
| "5번에 느낌 활기찬, 선포 추가" | (5, 느낌, [활기찬, 선포]) |
| "12번이랑 87번에 5월 성월 붙여줘" | ([12, 87], 성월, 5월) |
| "1-10번에 부활 시기 적용" | ([1..10], 시기, 부활) |
| "50번 성경 마태 28장 16-20절" | (50, 성경, 마태28:16-20) |
| "100번 곡 가톨릭성가 모음집" | (100, 곡모음집, 가톨릭성가) |

**번호 표현**:
- 단일: `5`, `5번`, `5번 곡`
- 복수: `12, 87` / `12랑 87` / `12와 87`
- 범위: `1-10`, `1~10`, `1번부터 10번까지`

**타입 키워드**:
- 성경 / 성서 / 성구 → `성경`
- 성월 / 월 → `성월`
- 시기 / 전례시기 / 절기 → `시기`
- 대축일 / 축일 → `대축일`
- 역할 / 미사 / 카테고리 → `역할`
- 느낌 / 분위기 / 정서 → `느낌`
- 키워드 / 태그 → `키워드`
- 곡모음집 / 성가집 / 모음집 → `곡모음집`

타입이 명확하지 않으면 사용자에게 되묻는다. 예:
> "2번 곡에 갈릴래아 추가" → "갈릴래아를 어떤 타입으로 추가할까요? 키워드 / 대축일 / 기타?"

## 실행 흐름

### Step 1: 자연어 파싱

`$ARGUMENTS` 또는 사용자 메시지에서 `(번호, 타입, 값)` 추출. 모호하면 되묻기.

### Step 2: 사용자 확인 (선택)

복수 곡이거나 vocab 위반 가능성이 있으면 한 번 더 확인:

> 12, 87번 곡에 `성월=5월`을 추가합니다. 진행할까요?

단일 곡 + 명확한 vocab이면 바로 진행해도 됨.

### Step 3: 스크립트 호출

```bash
python scripts/add_tag.py <번호목록> <타입> <값1> [값2 ...]
```

예시:
```bash
python scripts/add_tag.py 2 키워드 갈릴래아
python scripts/add_tag.py 5 느낌 활기찬 선포
python scripts/add_tag.py 12,87 성월 5월
python scripts/add_tag.py 1-10 시기 부활
python scripts/add_tag.py 50 성경 마태28:16-20
```

옵션:
- `--dry-run`: xlsx 변경 없이 결과 미리보기

### Step 4: 결과 보고

스크립트 출력을 그대로 사용자에게 전달:
- 추가 N건 / 중복 N건 / vocab 위반 N건
- xlsx 저장 결과
- rebuild 안내

### Step 5: vocab 위반 처리

스크립트가 `[reject] vocab 위반`을 보고하면, 허용 값 목록을 사용자에게 제시하고 다른 값을 제안하거나 다른 타입(예: 키워드)으로 변경할지 묻는다.

예:
> '잘못된값'은 느낌 vocab에 없습니다.
> 허용: 활기찬·장엄한·서정적·고요한·기쁜·애원하는·선포·묵상적
> 다음 중 어떻게 처리할까요?
> 1. 다른 vocab 값으로 변경 (어떤 값?)
> 2. 키워드 타입으로 추가 (vocab 제약 없음)
> 3. 취소

## vocab 요약 (docs/spec/vocab.md 동기화)

| 타입 | 허용 값 | 비고 |
|---|---|---|
| `시기` | 대림·성탄·사순·부활·연중 | 5종 고정 |
| `성월` | 1월 ~ 12월 | 12종 |
| `역할` | 입당·봉헌·성체·파견·묵상·감사·찬미·화답·주님의기도·마침 | 10종 |
| `느낌` | 활기찬·장엄한·서정적·고요한·기쁜·애원하는·선포·묵상적 | 8종 |
| `성경` | `{책}{장}[:{절시작}[-{절끝}]]` 형식 | 형식 검증만 |
| `대축일` | 자유 (공식 대축일명 권장) | 제약 없음 |
| `키워드` | 자유 | 제약 없음 |
| `곡모음집` | 자유 (예: 가톨릭성가, 야훼이레) | 제약 없음 |

## xlsx 잠금 충돌

엑셀에서 곡정보.xlsx를 열어둔 상태면 스크립트가 PermissionError로 종료한다.
사용자에게:
> 곡정보.xlsx가 엑셀에서 열려 있습니다. 저장 후 닫고 다시 시도해주세요.

재시도 옵션 제공.

## rebuild 정책

**배치 모드**: 매 태그 추가마다 rebuild하지 않음. 사용자가 여러 태그를 연속 추가한 뒤 한 번에:

```bash
python scripts/rebuild.py
```

스킬은 마지막에 "rebuild 필요" 안내만 출력. 명시적으로 "지금 빌드해줘"라고 하면 그때 호출.

## 원칙

- **xlsx만 수정** — songs.json 직접 갱신 금지
- **vocab 엄격** — 느낌·역할·시기·성월은 vocab 외 값 거부
- **중복 방지** — 같은 (번호, 타입, 값)은 skip
- **외부 호출 없음** — 순수 로컬
