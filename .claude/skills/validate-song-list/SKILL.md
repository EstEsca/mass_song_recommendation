# 곡목록 검증 스킬

songs.json의 제목/작곡자가 정확한지를 외부 데이터와 대조하여 검증한다.

## 실행 흐름

### Step 1: 진리표 DB 확인

사용자에게 묻는다:

> 검증에 사용할 진리표(정답) DB가 있나요?
> - **A**: maria.catholic.or.kr 크롤링 데이터 사용 (가톨릭성가 곡만)
> - **B**: 사용자가 별도 파일 제공
> - **C**: 인터넷 검색으로 검증 (명시 요청, 토큰 소모)

기본값: **A** (로컬 maria 데이터로 즉시 검증)

### Step 2-A: maria DB 교차 검증 (로컬, 무료)

`scripts/crawler/data/maria_sungga.jsonl`과 songs.json을 제목 매칭하여:

**비교 항목:**
- 제목 일치 여부
- 작곡자 일치 여부

**불일치 분류:**

| 유형 | 설명 | 예시 | 심각도 |
|------|------|------|--------|
| 포함 관계 | 한쪽이 다른쪽을 포함 | "Adolphe Adam / 최재용 편" vs "Adolphe Adam" | 낮음 (편곡자 추가) |
| 작곡/작사 혼동 | 작곡자와 작사자가 뒤바뀜 | "Isaac Watts" vs "G.F.Handel" | 중간 (역할 구분 필요) |
| 오기 | 이름 자체가 다름 | "류선오" vs "원선오" | 높음 (확인 필요) |
| 표기 차이 | 같은 사람, 다른 표기 | "F. Lambillotte" vs "P. Lambillotte" | 중간 (확인 필요) |

### Step 2-C: 인터넷 검색 검증 (고비용, 명시 요청)

maria에 없는 곡에 대해 사용자가 명시 요청 시:
- WebSearch로 `"곡제목" 작곡 가톨릭 성가` 검색
- 결과에서 작곡자 정보 수집
- songs.json의 작곡자와 대조
- 불일치 시 검색 결과의 작곡자를 **교정 후보**로 제안

### Step 3: 결과 보고

```
=== validate-song-list 결과 ===
대상: N곡
일치: N곡 ✅
불일치: N곡 ⚠️
  - 포함 관계 (편곡자 차이): N곡 (낮음)
  - 작곡/작사 혼동: N곡 (중간)
  - 오기 의심: N곡 (높음)
  - 표기 차이: N곡 (중간)
```

곡별 상세:
```
[119] 무엇을 먹을까 — 오기 의심
  우리: 임석수 / maria: 원선오
  → 교정 제안: 원선오 (maria 공식)
```

## 원칙

- **검증만 한다.** songs.json 수정은 사용자 승인 후 별도 수행.
- Step 2-A는 로컬 데이터로 무료. Step 2-C는 명시 요청 시에만.
- 불일치의 심각도를 분류하여 우선순위 안내.
- 같은 곡에 작곡자와 작사자가 따로 있을 수 있음을 고려.
