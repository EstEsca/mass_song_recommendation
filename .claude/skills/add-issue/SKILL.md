# 이슈 추가 스킬

ISSUES.md 파일에 새 이슈를 추가합니다.

## 실행 흐름

### Step 1: 현재 이슈 파일 읽기

`ISSUES.md`를 읽어서:
- 마지막 이슈 번호를 확인 (다음 번호 = 마지막 + 1)
- 현재 테이블 구조를 파악

### Step 2: 이슈 정보 정리

사용자 입력(`$ARGUMENTS`)에서 다음을 파악:
- **제목**: 간결한 이슈 제목
- **설명**: 구체적 내용 (사용자가 충분히 제공하지 않으면 물어보기)
- **상태**: 기본값 "시작 전" (사용자가 별도 지정 시 반영)

상태 옵션: 시작 전 / 진행 중 / 스킵 / 리뷰 중 / 완료

### Step 3: 테이블에 행 추가

ISSUES.md의 이슈 테이블 마지막 행 뒤에 새 행을 추가:

```
| {번호} | {상태} | {제목} | {설명} | {오늘 날짜 YYYY-MM-DD} |
```

### Step 4: 확인

추가된 이슈를 사용자에게 보여줍니다:
> 이슈 #{번호} "{제목}" 을 등록했습니다.

## 주의사항

- 이슈 번호는 항상 자동 증가 (중복 불가)
- 등록일은 오늘 날짜 자동 입력
- 테이블 형식이 깨지지 않도록 주의
- 한 번에 여러 이슈를 요청하면 각각 별도 행으로 추가
